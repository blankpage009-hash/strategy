제미나이 API 키
키는 이 기기의 브라우저 안에만 저장됩니다. 백업 파일에도 들어가지 않으므로 폴더를 그대로 복사해 줘도 키는 따라가지 않습니다. 다른 사람이 쓰려면 각자 키를 발급받아 넣어야 합니다. 발급: aistudio.google.com → Get API key

잘 모르면 그대로 두세요. 이 모델이 바쁘면 자동으로 아래 단계 모델로 내려가서 다시 시도합니다.
자료 종류
필터 막대에 보이는 자료 종류입니다. 여기서 더하거나 이름을 바꾸거나 지우고, ↑ ↓ 로 순서를 바꿀 수 있습니다. 자료가 들어 있는 종류는 지울 수 없습니다. (필터 칩을 마우스 오른쪽 클릭해도 같은 메뉴가 열립니다.)
파일 이름 → 자료 종류 자동 지정
자료를 올릴 때 파일 이름에 아래 포함 단어 중 하나라도 들어 있으면 그 줄의 자료 종류로 자동 지정됩니다. 단어는 쉼표(,)로 여러 개 적을 수 있고, 띄어쓰기는 무시합니다.

프로그램 갱신
웹주소로 쓰는 경우, 프로그램이 바뀌었는데 예전 화면이 계속 나오면 눌러 주세요. 자료는 지워지지 않습니다.
동기화 (GitHub)
PC 와 아이패드를 같은 상태로 맞추는 기능입니다. 올리기 전에 이 기기 안에서 암호화하므로 GitHub 저장소에는 알아볼 수 없는 덩어리만 놓입니다. 올라가는 것은 자료(문서·PDF·필기·AI Note)와 회의 종류·할 일·요약·발표 스크립트·메모·회의 Agenda 뿐입니다. 제미나이 API 키는 어떤 경우에도 올라가지 않습니다. 이 기기만의 설정(그리기 도구, 마지막에 보던 자료 등)도 올라가지 않습니다. 켜 두면 앱을 열 때·창을 다시 앞으로 가져올 때·창이 열려 있는 동안 1분마다 다른 기기에서 바꾼 것을 받아오고, 이 기기에서 바꾼 것은 저장 5초 뒤에 올립니다. 다른 기기에서 올린 PDF 원본은 그 자료를 처음 열 때 내려받아 이 기기에 보관합니다. 양쪽에서 같은 것을 고쳤으면 나중에 올린 쪽이 남습니다. 토큰을 넣지 않으면 아무 통신도 하지 않습니다 — 다른 사람에게 앱 파일만 건네줘도 지금과 완전히 같게 동작합니다. 저장소가 너무 커지면 새 저장소를 만들어 이름만 바꾸면 됩니다. 토큰이 만료되면(보통 1년 뒤) 자동 동기화가 멈추고 아래 상태 줄에 빨갛게 뜹니다 — 새 토큰을 만들어 다시 넣으면 이어집니다. 저장소를 실수로 공개(Public)로 바꾸면 하루 안에 자동으로 알아채 동기화를 끕니다.

토큰 (fine-grained)
부록 A 대로 만든 토큰을 붙여넣습니다. Contents: Read and write 권한 하나만 있으면 됩니다. 토큰은 이 기기의 브라우저 안에만 저장됩니다.
암호문구
두 기기에서 반드시 같은 암호문구를 넣어야 서로 맞춰집니다. 잃어버리면 저장소의 자료를 아무도 풀 수 없습니다. 비밀번호 관리자에 꼭 저장해 두세요.
지금 동기화는 받을 것을 받고 올릴 것을 올립니다(평소엔 자동으로 됩니다). 전부 올리기는 이 기기의 모든 자료를 서버로 올리고, 전부 내려받기는 서버의 모든 자료를 다시 받습니다. 자료가 많으면 몇 분 걸릴 수 있고, 도중에 창을 닫아도 다음에 이어서 진행됩니다.

백업
데이터만은 회의록·요약·할 일·스크립트·메모·회의 Agenda·자료 종류 설정을 파일 하나로 내보냅니다(.json). 원본 + 데이터는 위 내용에 PDF 원본과 AI Note 첨부 파일까지 함께 담은 .zip 입니다(용량이 큽니다). PDF 원본만은 자료 목록과 PDF 원본만 담은 .zip 으로, 데이터는 들어가지 않습니다. 자료 목록은 세 가지 모두에 들어가므로 어느 것이든 단독으로 복원됩니다. 불러오기는 세 형식 모두 받습니다.
