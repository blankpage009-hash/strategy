제미나이 API 키
키는 이 기기의 브라우저 안에만 저장됩니다. 프로그램 파일이나 백업 파일에는 들어가지 않으므로, 폴더를 그대로 복사해 줘도 키는 따라가지 않습니다. 키 발급: aistudio.google.com → Get API key
모델 이름
잘 모르면 그대로 두세요. 모델은 이따금 바뀝니다. ‘쓸 수 있는 모델 보기’ 를 누르면 내 키로 지금 쓸 수 있는 것만 보여 주고, 눌러서 고를 수 있습니다.
요약은 자동으로 만들지 않습니다. 오른쪽 Executive Summary 탭의 AI로 요약 만들기 단추를 눌렀을 때만 만듭니다.
회의 종류
필터 막대에 보이는 회의 종류입니다. 여기서 더하거나 이름을 바꾸거나 지울 수 있습니다. 자료가 들어 있는 종류는 지울 수 없습니다. (필터 칩을 마우스 오른쪽 클릭해도 같은 메뉴가 열립니다.)
파일 이름 → 회의 종류 자동 지정
자료를 올릴 때 파일 이름에 아래 포함 단어 중 하나라도 들어 있으면 그 줄의 회의 종류로 자동 지정됩니다. 단어는 쉼표(,)로 여러 개 적을 수 있고, 띄어쓰기는 무시합니다.
예: 임원회의 ← 본부장회의, 부재중 업무보고
