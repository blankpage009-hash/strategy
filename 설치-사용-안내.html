01

설치

1분
  1. 압축 파일을 풀어 폴더째로 둡니다. 폴더 안에 whats-the-strategy-v1.0.html 과 lib 폴더가 함께 있어야 합니다.
  2. whats-the-strategy-v1.0.html 을 더블클릭하면 브라우저에서 바로 열립니다. 이것이 전부입니다.
  3. 자주 쓴다면 열린 화면을 즐겨찾기에 넣어 두세요. 늘 같은 PC · 같은 브라우저로 여세요.
html 파일만 따로 옮기거나 lib 폴더를 지우면 PDF 가 열리지 않습니다. 폴더 이름은 바꿔도 됩니다.
02

동봉된 백업 불러오기

처음 한 번
  1. 상단바 맨 오른쪽 설정 → 백업 → 불러오기
  2. 동봉된 백업 파일(.zip 또는 .json)을 고릅니다.
  3. "백업을 불러올까요?" 창에서 확인. 자료 목록 · 회의록 · 요약 · 할 일이 채워집니다.
.zip 은 PDF 원본이 들어 있어 몇 분 걸릴 수 있습니다. 끝날 때까지 창을 닫지 마세요. 같은 자료가 이미 있으면 덮어씁니다.
03

주요 기능

7 항목
기능어디에무엇을
자료 올리기왼쪽 MATERIALS → UploadPDF 를 끌어다 놓고 등록 시작. 여러 개 한 번에. 파일 이름으로 회의 종류 · 날짜가 자동 지정됩니다.
찾기상단 검색창 · Filter 막대모든 자료의 본문까지 검색. Filter 칩으로 회의 종류별로 걸러 봅니다 (Select All 로 전부 켜기).
보기 · 그리기가운데 뷰어쪽 넘김 ← → · 확대 · 전체화면. 펜 · 형광펜으로 자료 위에 바로 표시 (iPad 는 애플펜슬).
다섯 탭오른쪽 칸SUMMARY 요약 · NOTE 회의록 · TASKS 할 일 · SCRIPT 쪽별 스크립트 · MEMO. 적는 즉시 저장 — 저장 단추가 없습니다.
AI NOTENOTE 탭 → Generate AI NOTE받아 적은 회의록을 AI 가 정식 회의록 한 장으로 정리. EDIT · COPY · EXPORT(PDF). 제미나이 API 키가 필요합니다 (설정 → AI NOTE).
AI 요약SUMMARY 탭 → Generate AI Summary지금 펼친 쪽만 AI 가 핵심 내용 · 주요 수치 및 현황 · 비고 세 카테고리 카드로 요약. 쪽마다 따로 만들고, ‹ › 로 쪽을 넘기며 봅니다. EDIT 로 고칠 수 있고, 같은 제미나이 API 키를 씁니다.
회의 Agenda상단바 달력 단추주차별 안건 표. 적어 두면 AI NOTE 가 참고합니다.
백업설정 → 백업데이터만 (.json) 가볍게 자주 / 원본 + 데이터 (.zip) 기기 옮길 때. 불러오기는 둘 다 받습니다.
04

주의 사항

꼭 읽기
  • 저장자료는 이 PC 의 브라우저 안에만 저장됩니다. 인터넷 · 서버에 올라가지 않으며, 다른 PC · 다른 브라우저에서는 보이지 않습니다.
  • 삭제브라우저의 인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터 를 지우면 자료도 함께 지워질 수 있습니다. 설정 → 저장 공간 → 저장 보호 요청 을 한 번 눌러 두세요.
  • 백업그래서 정기 백업이 필수입니다 — 설정 → 백업 → 데이터만 (.json). 전체 지우기는 되돌릴 수 없습니다.
  • AI인터넷을 쓰는 것은 AI NOTE 뿐입니다. API 키는 각자 발급(aistudio.google.com → Get API key)해 넣고, 키는 백업에 들어가지 않습니다.
  • iPad설정 → 이 기기에 PDF 원본 저장 → 글자와 요약만 을 권장합니다. 원본은 PC 에서 보세요.
